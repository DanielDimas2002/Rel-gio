# ⏰ **Relógio Analógico em JavaScript** 🎯

Este é um projeto simples de **relógio analógico** utilizando **HTML**, **CSS** e **JavaScript**. O relógio exibe as horas, minutos e segundos de forma analógica, com uma animação suave que atualiza os ponteiros em tempo real. 🕰️

## 🔧 **Tecnologias Usadas**

- **HTML**: Estrutura da página.
- **CSS**: Estilização visual do relógio.
- **JavaScript**: Lógica para movimentar os ponteiros do relógio.

## 🌟 **Funcionalidades**

- Exibição de um relógio analógico.
- Atualização automática dos ponteiros a cada segundo.
- Ponteiro de horas, minutos e segundos com movimento suave. ⚡

## 🖥️ **Como Rodar o Projeto**

1. Clone o repositório para o seu computador:

    ```bash
    git clone https://github.com/DanielDimas2002/relogio-analogico.git
    ```

2. Entre no diretório do projeto:

    ```bash
    cd relogio-analogico
    ```

3. Abra o arquivo `index.html` no seu navegador para ver o relógio funcionando.

## 🕰️ **Como Funciona**

O relógio é formado por três ponteiros:
- **Ponteiro das horas**: Atualiza conforme o horário, levando em consideração os minutos.
- **Ponteiro dos minutos**: Atualiza a cada minuto.
- **Ponteiro dos segundos**: Atualiza a cada segundo.

### O funcionamento é o seguinte:
- O ponteiro de horas se move gradualmente a cada hora, considerando também o movimento dos minutos.
- O ponteiro de minutos se move suavemente a cada 60 minutos.
- O ponteiro de segundos se move a cada segundo, com rotação contínua.
